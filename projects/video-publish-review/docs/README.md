# video-publish-review 目录说明

- `workflows/`：项目工作流 SOP。
- `outputs/account-rules.md`：账号级规律库。
- `outputs/retrospectives/<date>-<slug>/`：每支已发布视频的复盘册。
- `outputs/topic-forward/<date>/`：选题前瞻按日期归档，包含 `topic-forward.md` 与 `signals.json`。
- `logs/`：运行日志，只保留项目执行证据。
- `experience-candidates/`：待用户确认的经验候选；确认后进入 Experience Curator 流程。
- `scripts/`：项目专属脚本；通用脚本放入 `.ai/skills/<skill>/scripts/`。
