# Account Profile: 账本两面 v1

## 定位

「账本两面」是公司研究型双人财经账号。账号资产包括栏目名、两位原创主持人、固定音色、视觉 Token、节目结构和质量门禁。参考视频只贡献已蒸馏的结构与视觉语法，不进入日常运行。

## 节目规格

- 默认节目模式：`host_analyst`（主理人追问 + 分析师展开）；只有选题确实存在对等观点冲突时，才显式指定 `debate`
- 目标时长：18–25 分钟
- 画幅：1920×1080，16:9，30fps
- 结构：客观数据冷开场 → 本期目录 → 双主持人自我介绍 → 8–9 个核心话题 → 双总结 → 互动钩子；manifest 层固定为 `COLD_OPEN → INTRO → T01...`
- 自我介绍：每位主持人用 1–2 句说明姓名、人设和看问题的方法；这是固定节目开场，不依赖公司研究数字
- 冷开场：可选 2–4 个公司专属客观事实卡（阶段性股价变化、估值水平、营收/利润/现金流、业务规模、资产组合或公告变化），由本期 thesis 选择最能体现公司矛盾的一组；只做背景事实，不构成建议；估值不是通过门槛
- 冷开场音频先由主理人提出事实冲突，再由分析师回应其关系；画面卡片只呈现客观数据，不重复完整对白
- 冷开场表达契约：`公司特征事实 + 经营矛盾 + 开放问题`；允许按公司使用资产到收入、产品到订单、规模到变现、事件到兑现等不同入口。优先使用“涨了快三倍”“反而下降了”等自然表达，不使用“利润快涨三倍”等书面化短语；不得把上一家公司开场的事实组合和句式直接复用
- 短视频开场沿用“公司特征事实 + 经营矛盾 + 开放问题”的逻辑，可按公司压缩为资产到收入、产品到订单或事件到兑现；不能只报数字或先替观众下结论
- `host_analyst` 每个话题：主理人抛出问题 → 分析师先回应再展开 → 主理人追问/复述 → 分析师补证据和限定 → 主理人转场；不要求双方等量发言
- `debate` 仅作为显式覆盖模式：事实矛盾 → 双方立论 → 反驳 → 新证据 → 类比降维 → 双方收束
- 可选估值话题只允许官方或券商来源支持的估值水平、历史分位、同行比较和市场假设；不得给目标价、评级或买卖方向
- 每个话题建议 2–4 分钟；不能用单个长段落代替回合制
- 默认发言比例：主理人约 30–40%，分析师约 60–70%；主理人负责节目节奏和观众问题，分析师负责主要事实、数据和判断边界
- 默认不制造对等辩论；分析师可以提出风险限定，但不把每次回答改写成反方交锋

## 视觉固定层

- 左上：当前说话人胶囊
- 顶部居中：公司名 + 栏目标识
- 右上：两行免责声明
- 标题区：话题编号 + 蓝色提问式标题
- 内容区：1–3 个数据卡/对比条/列表/路线图
- 内容区不放完整逐句对白，也不放“风险视角/数据视角”等流程标签；它只放证据卡、图表和必要的结构化解释
- 视觉优先级：图表 > 表格/指标卡 > 文字；能用图表表达的比较、趋势、贡献和关系不得退化成纯文字
- 底部上方：紫色粗体描边字幕，只显示当前真实音频 turn
- 底部：真实话题标题导航，当前话题高亮，并由音频总时长驱动连续进度条

## 视觉语义

- 红：风险、警示、负面
- 绿：增长、正面、改善
- 橙：中性、待验证、冲突
- 蓝：栏目和品牌主色

## 复用边界

- 公司名、数字、话题标题、证据、字幕、音频路径全部来自 episode manifest。
- 模板源码不得写死任何公司事实。
- 每次运行必须生成 `account-profile-version` 和 `episode-id`，便于回归比较。
- 通用字体、音色、品牌图形和音乐通过顶层 `.ai/assets/` 的 `resource_key` 选择；`account-profile` 只保存本项目的角色/视觉用途映射；公司输出目录只保存运行时副本和公司特定产物。
