# 账本两面节目模式与对话规范 v2

## 默认模式

- `format_mode` 默认值为 `host_analyst`，由账号 profile 继承到每个公司的 episode manifest。
- `debate` 不是隐式 fallback；只有选题配置显式指定时才启用。
- `host_analyst` 中 `zhiwei` 是主理人，`shenyan` 是分析师。主理人约占 30–40% 发言时长，分析师约占 60–70%。
- 语气词不是填充物：它必须有 `backchannel_target` 或明确的提问/承接功能；开场自我介绍默认不加“嗯”。

### `host_analyst` 角色契约

- 主理人：提出观众真正会问的问题、承接上一句、要求解释、复述阶段结论、组织转场。
- 分析师：先回答主理人的问题，再给证据、解释机制、补充限制条件和验证路径。
- 主理人可以质疑，但不承担完整反方论证；分析师可以提示风险，但不把每次回答写成辩论反击。

### `debate` 覆盖模式

- 只有 manifest 明确写入 `format_mode: "debate"` 时，才允许双方接近等量发言、连续反驳和对立立场收束。

## 对话不是轮流念稿

每个 turn 必须回答、承认、追问、质疑或补充上一句。只有在新话题的第一句允许直接立题；同一话题后续 turn 必须具备：

- `reply_to_turn_id`
- `interaction_type`: `acknowledge` / `challenge` / `clarify` / `counter_evidence` / `interrupt` / `summarize`
- `response_action`: `content` / `backchannel`
- `emotion`: `curious` / `skeptical` / `surprised` / `firm` / `relieved` / `cautious`
- `delivery`: `normal` / `pause_before_number` / `stress_contrast` / `short_pause`

情绪和口播文本必须共同设计，不能先写一套固定台词、再给每句贴情绪标签。每句生成时同时回答三个问题：这句话在回应谁？它要让观众感受到什么？哪些词和停顿能自然承载这种感受？

## 生成时的硬约束

这些规则应写入生成提示和结构化输出，而不是等成片后再补救：

- 先读取上一句的语义对象，再生成回应；不得先生成孤立段落再拼接 speaker。
- 先读取 `format_mode` 和角色，再生成回应；不得把 `host_analyst` 自动生成成双方轮流辩论。
- `host_analyst` 中分析师回答必须先解决主理人的问题，再引入新数据；主理人下一句优先承接解释，不得立即切换为另一条反方论点。
- 每句同时生成 `text`、`reply_to_turn_id`、`interaction_type`、`emotion` 和 `delivery`。
- 句首出现“对、嗯、没错、好”等短回应时，同时生成 `response_action=backchannel`、`backchannel`、`backchannel_target`、`filler_position=start`、`delivery=short_pause` 和正值 `pause_after_ms`；保留完整口播文本，但不能让短词只存在于普通长句里。
- 涉及语气和句末语调时，同时生成 `backchannel`、`backchannel_target`、`filler_position` 和 `question_ending`；没有功能就写 `none`，不要让 TTS 自己猜。
- 数字在生成时选择自然表达：`6.46%` → “接近 7%”或”超过 6%”；禁止”6%多”。
- **金额简化**：大额数字只保留整数级别，不精确到小数点后一位。`58.50亿` → “五十八亿”或”接近五十九亿”；`7.29亿` → “七个亿”或”七亿三”（但”七亿三”已接近边界，优先用”七个亿”）。禁止”五十八亿五””七个亿三””五亿六千九”等过于精确的口语化表达。规则：亿级数字只说整数亿，千万级四舍五入到亿。
- **百分比简化**：`12.00%` → “十二个点”或”百分之十二”；`0.40pct` → “零点四个百分点”或直接说”基本持平”。禁止”十二点零零”等冗余小数。
- **英文缩写读法**：CPU 保持”CPU”读法；GPU 可说”显卡”或”GPU”；ARM 作为整体词发音（不逐字母拼读）；NVIDIA 用中文”英伟达”。口播中遇到英文品牌/缩写时，禁止逐字母拼读，优先用自然发音或中文通用名。
- 开场不机械加语气词；主理人提问可按意图选择句末：开放问题通常不用助词，确认问题可用”对吗/吧”，追问可用”呢/吗”，同一段不要连续重复。
- 分析师回应只有在承接上一句时才使用“嗯/好/对/明白”等起音；起音之后必须立即回答问题，不能用语气词拖延。
- 同一语气词 30 秒内不重复；每 20 秒最多一个明显语气动作，除非它明确表示回应、打断或确认。
- 生成后只保留事实、时间轴和公开文案三类硬门，互动感不另设一套复杂的后置评分体系。

## 可复用的自然互动句式

- 承认后转折：“对，这个数字确实不错，但我还要追问一层。”
- 自然承认：“这个问题问得很准，我先把规模摆出来。”
- 轻微打断：“等一下，这里不能只看收入。”
- 追问：“那利润为什么没有同步跟上？”
- 补证据：“我补一个数据，这正好能说明问题。”
- 暂缓结论：“这个方向可以成立，但现在还不能下定论。”

语气词不是装饰。每个 20 秒左右的对话段落最多使用 1–2 个明显语气动作，避免“嗯、对、但是”机械重复。

## 模式化回合要求

- `host_analyst` 每个话题至少出现一次主理人追问、一次分析师直接回答、一次主理人复述/澄清、一次分析师补证据和一次主理人转场。
- `debate` 才要求双方对等立论、承认后转折和双方反证。

## 情绪强度

- `curious`: 轻微上扬，适合追问。
- `skeptical`: 句首停顿，强调反证。
- `surprised`: 只用于新数据，不用于每个数字。
- `firm`: 句尾收紧，适合结论。
- `cautious`: 放慢限定词，如“目前”“至少从这一期看”。

情绪必须服务于证据关系，不能用夸张情绪替代事实。

## 文本—情绪兼容性

- `curious` 不强行使用“对”作为句首，可用“这个问题问得很准”“我想追问一层”。
- `skeptical` 使用限定、反问和短停顿，不连续堆叠“但是/不对”。
- `firm` 使用明确判断和短句，避免过度解释。
- `thoughtful` 使用“我更愿意”“放回时间里看”等缓冲表达。
- 句首出现爆音、吞字或不自然起音时，优先改写文本，再调整情绪参考音频；不能只靠后期音频处理掩盖。
