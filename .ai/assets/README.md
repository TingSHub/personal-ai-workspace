# Workspace reusable assets

`.ai/assets/` stores validated resources that can be consumed by more than one project. Each resource directory contains its own `ASSET.md`, source/license information and the binary asset.

Projects do not copy these files into `account-profile`. A project profile selects a `resource_key` and assigns a project role or visual purpose.

## Current resource kinds

- `fonts/`: licensed display and body fonts
- `voices/`: reusable voice references and registered emotion bundles

Candidates, company-specific extracts and failed experiments remain in their project output/experiment directories until separately accepted.
