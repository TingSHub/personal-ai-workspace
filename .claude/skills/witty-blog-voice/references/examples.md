### 1. 标题党（公众号爆款标题）

- 平淡：如何提高时间管理效率
- 犀利：你不是时间不够，你是把"刷手机"当成了呼吸
- 平淡：年轻人消费观变化
- 犀利：这届年轻人省钱省出了一种行为艺术
- 平淡：关于拖延症的科普
- 犀利：拖延症晚期患者指南：如何把"明天再做"过成一种生活方式

### 2. 开篇钩子

- "先说好，这篇可能得罪人，但你大概率中枪。"
- "我观察了身边三十个'自律达人'，发现他们只是……睡得比较早。"
- "别急着反驳，你上一次'坚持到底'的事，是不是只有外卖凑满减？"

### 3. 吐槽 / 段子

- 现象：知识付费买了不学。
- 段子：我的网课收藏夹，是我这辈子最体面的"假装努力"现场。每一门没打开的课，都在替我圆一个"我在变好"的梦。
- 现象：朋友圈精修图。
- 段子：朋友圈里的生活，美得像加了十级滤镜的样板间——好看，但没人真住。

### 4. 神回复

- 问：怎么看待"鸡汤"？答：喝多了齁得慌，但饿的时候还真顶用，建议当调料别当主食。
- 问：要不要辞职追梦？答：你先把"梦"写清楚，别拿"不想上班"当梦想。
- 问：怎么变自信？答：少跟别人比，多跟昨天的自己比——虽然昨天的你也很菜。

### 5. 产品 / 体验差评风

- 原：这个 App 加载很慢。
- 犀利：打开它我顺手泡了杯茶，茶凉了它还在转。加载界的禅修大师。
- 原：客服响应慢。
- 犀利：问了句售后，客服的回复速度，让我怀疑他是不是先去考了个证。

### 6. 自嘲式幽默

- "我这人最大的优点，就是永远对'计划'保持一种……不执行的尊重。"
- "别人是'干就完了'，我是'想完了就完了'。"
- "我的执行力，和我的减肥计划一样，永远停留在'明天开始'。"

### 7. 收尾金句库

- "成年人的体面，就是一边吐槽，一边把日子过下去。"
- "清醒地活着，比快乐地糊涂着，累，但值。"
- "你可以不完美，但别拿不完美当借口——借口这东西，用多了会过期。"
- "世界不欠你一个解释，你也不欠世界一个完美。"

### 8. 翻车对照（别说成这样）

- ❌ "你就是懒，别找借口。" → 攻击人。改成："'没时间'这借口用多了，连自己都骗不过。"
- ❌ "XX 地区的人就是不行。" → 地域歧视。改成针对现象，不针对群体。
- ❌ 长篇骂街、脏话连篇 → 越红线。毒舌靠逻辑和修辞，不靠音量。

### 9. 长文改写完整范例（技术产品对比）

场景：把一篇"Claude Code vs OpenCode"的平淡公众号文改成毒舌风。保留全部信息（对比点、操作步骤），只换语气。

- 原开篇：上周我推荐朋友试 Claude Code。他三步卡死：官网打不开，没有外币信用卡，好不容易搞到 key，连 API 还是超时。
- 改开篇：上周我安利朋友试 Claude Code。人家三步走完直接悟了——敢情这玩意儿是专门给中国开发者设的"三关闯关游戏"。第一关：官网打不开。第二关：没有外币信用卡。第三关：好不容易搞到 key，API 还超时，主打一个"我都这么努力了，你还是不配"。

- 原小标题：第二道墙：支付与账号
- 改小标题：第二道墙：支付与账号——$20 的会员，先过签证
- 原句：国内双币卡有时被风控，退款也麻烦。
- 改句：国内双币卡偶尔被风控，退款流程比写 bug 还心累。

- 原收尾：开源的意义就在这。它不一定最漂亮，但它属于用的人。
- 改收尾：开源的意义就在这。它不一定最漂亮，但它是你的。工具是为人服务的，不是给人的耐心出考题的。

 技法提炼：标题反讽、夸张（"三关闯关游戏"）、把抽象壁垒拟人成"签证 / 门禁"、用"早说啊""比写 bug 还心累"这类口语自嘲拉近距离、结尾用金句收束。全程只调侃产品和流程，不攻击具体活人。

### 10. 鲁迅风范例（冷峻白描投枪）

神韵：横眉冷对、白描入骨、于无声处听惊雷。不笑，每句像手术刀。半文半白，用"大抵""向来""无非是""……罢"收尾。

- 原：很多人热衷在朋友圈展示自己很努力，其实只是一种自我安慰。
- 鲁迅风：大抵是这样罢：众人极爱在朋友圈证明自己"在努力"，仿佛贴了图，那努力便真算数了。其实不过画饼充饥，自己骗自己，倒也其乐融融。
- 原：一些所谓的知识付费课程，质量很差却卖得很贵。
- 鲁迅风：我向来是不大信"知识"二字前面加个"付费"便金贵的。倘使内容空洞，价钱再高，也不过是体面的收割罢——买的人得了安慰，卖的人得了银钱，两便。

技法提炼：白描（不修饰地写丑态）、反语（"体面""其乐融融"）、归谬（把荒唐推到极端）、半文半白收尾"……罢"。只借"冷"与"白描"，不碰政论红线。

### 11. 韩寒风范例（痞锐调侃）

神韵：赛车手式直给、逻辑鬼才、把严肃话题拉到地面摩擦。短句横飞，大白话开道，结尾甩反杀。

- 原：很多年轻人嘴上说躺平，其实还是忍不住和别人比。
- 韩寒风：说躺平的都是嘴上躺平。真躺的人连这条朋友圈都懒得发。你那不叫躺平，叫趴着刷手机还顺便看看别人赚没你多。
- 原：有些所谓的"成熟"，只是学会了忍气吞声。
- 韩寒风：所谓成熟，说白了就是被人敷衍习惯了，还觉得是自己脾气变好了。这事儿不值得庆祝，顶多算认命比较早。

技法提炼：短句 + 大白话（"说白了""这事儿"）、反差（高大上概念配生活琐事）、冷幽默反杀结尾。态度痞、逻辑锐，不脏话不损真人。

### 混搭速记

- 鲁迅的冷 + 韩寒的痞 = 冷眼拆台、白描带刺。例："大抵人人都爱谈格局，谈完该摸鱼摸鱼，该甩锅甩锅——这格局，倒像是给别人预备的。"
- 基础毒舌 + 鲁迅白描 = 不笑的犀利。
- 基础毒舌 + 韩寒调侃 = 笑着扎人。
