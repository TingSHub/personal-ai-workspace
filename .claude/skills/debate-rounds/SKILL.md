# 多空对决回合制(debate-rounds)

## R — 原文 (Reading)

> 欢迎来到苏晴多空局,我是房叔,20多年投资经验,见过太多看着贵其实不贵,和看着便宜其实是坑的故事。我是苏晴,做管理的,习惯看数据。
> 你这话没错,但得看趋势……
> 你这个定性不准确……
> 但还有一个数据你没法回避……
> 行,那咱们先看下一个话题……
> 所以总结一下……我从另一个角度总结……
> 你看好它的AI故事,还是担心它的利润薄如纸?咱们评论区见。
>
> — 叔晴多空局,《紫光股份》(全片结构)

---

## I — 方法论骨架 (Interpretation)

**多空局 = 对立人设 + 话题回合制**。核心不是"两个人吵架",而是**用立场冲突组织证据呈现**:

1. **对立人设**: 两个可辩护的稳定视角(价值/风险老手 vs 数据/趋势派),各自有方法论底色(经验判断 vs 数据驱动)
2. **话题拆解**: 把研究对象拆成 N 个核心话题(紫光:利润矛盾/AI 赛道/财务风险/股权/估值/政策/管制/治理/格局),每话题一个矛盾
3. **回合制**: 每话题循环 = 矛盾立题 → 空头立论 → 多头「你这话没错,但…」承认再反击 → 数据交锋(连环新证据「还有一个数据你没法回避」)→ 类比降维 → 收束(「总结一下」)→ 转场(「先看下一个话题」)
4. **双总结**: 片尾双方各自总结(风险方:现实/雷/未验证;逻辑方:赛道/确定性/龙头),不统一结论,观众自己判断
5. **互动钩子**: 以二选一问题收尾引导评论

**自动化适配(关键)**: 真人即时交锋不可自动化,但**预编排回合完全可行**——SCRIPT 阶段写死双方论点、数据、反驳顺序,配音用两个音色分饰,画面用「双方卡片交替」表达立场。这是「自动化的多空局」,不是「两个 AI 即兴吵架」。

## A1 — 书中的应用 (Past Application)

### 案例 1: 紫光股份 9 话题多空局
- **问题**: 22 分钟内容如何保持张力
- **方法论的使用**: 9 话题回合制,每回合至少一个新数据(毛利→商誉→担保→现金流→股权→估值→政策→管制→治理→格局)
- **结论**: 空头武器 = 风险结构化拆解(140亿商誉=净资产80%、320亿担保=净资产185%);多头武器 = 趋势与赛道(规模效应/价值链再分配/国产替代)
- **结果**: 全片无冷场;观众评论区自动分成两派(互动目标达成)

### 案例 2: 我们的成片(对照)
- **问题**: 茅台片 S7 反证 Scene 只出现一次且不交锋
- **方法论的使用**: 无反方持续在场,说服力来自信息完整而非交锋可信
- **结论**: 单一叙事形态(矛盾-解释-验证)适合企业研究深度内容,但争议性选题缺失「双视角张力」
- **结果**: 保留 f02 叙事弧为默认形态;争议性选题可切换 debate-rounds

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 选题本身有强争议(估值分歧/泡沫质疑/多空辩论),想要「交锋感」
2. 内容有双方都可辩护的证据(参考:紫光利润薄 vs 赛道好;茅台双降 vs 改革)
3. 想要评论区互动(二选一钩子)
4. 自动化链路想突破「单 AI 念稿」形态

### 语言信号 (用户的话里出现这些就应激活)

- "做成多空辩论" / "双视角" / "两个立场"
- "这个争议点怎么呈现" / "想要交锋感"
- "debate format" / "bull vs bear"

### 与相邻 skill 的区分

- 与 `video-hook-intro` 的区别: hook 管开场钩子;本 skill 管全片结构
- 与叙事弧(f02,工作流既有)的区别: 叙事弧是单立场解释(信任型);本 skill 是双立场交锋(互动型)
- 与 `number-perception`/`boundary-rewrite` 的关系: 回合内的数据呈现用 number-perception;双方定性用 boundary-rewrite 把控

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认选题可辩性**
   - 检查 Editorial Master 是否存在双方都有证据支撑的核心分歧(估值 vs 成长/风险 vs 赛道)
   - 完成标准: 至少 2 组对立证据,各可辩护
   - 判停条件: 无明显可辩性 → 说明并建议使用叙事弧(f02),不硬造辩论

2. **定义对立立场(双主持人人设)**
   - 房叔:价值/风险视角,敢下判断,尖锐定性(「搬运工的生意」)
   - 苏晴:数据/趋势视角,「你这话没错,但…」式承认再反击
   - 完成标准: 两个立场不重叠、都可被证据支持;人设与音色资产一致(见 `projects/investment-research-video/assets/voices/voices.md`)

3. **拆解话题与分配弹药**
   - 拆 N 个话题(建议 5-9 个),每话题:矛盾立题句 + 双方论点 + 至少一个新数据(双方各有)+ 一个类比(降维)
   - 完成标准: 每话题双方论点都有来源;弹药不重复(连环新证据原则)
   - 判停条件: 话题数量 > 9 或单个话题弹药不足,合并或裁掉

4. **预编排双人对话稿(自动化适配)**
   - 按「空头立论 → 多头反击 → 数据交锋 → 收束 → 转场」写死 SCRIPT;每句带说话人标记 `[房叔]` / `[苏晴]`,对话自然(含「你这话没错,但…」等回合句式)
   - 完成标准: SCRIPT 可直接进入双音色 TTS 交替合成,无需即兴

5. **双人视觉编排(对话卡片风)**
   - 画面:左右双人卡片(名字 + 立场标签「空/多」),当前说话者高亮,数据卡片随对话弹出(说话人引用数据时)
   - 完成标准: 画面与对话轮次一一对应(说话人切换 = 高亮切换),数据锚点对齐台词

6. **片尾双总结 + 互动钩子 + 边界校验**
   - 双方各自总结;二选一互动问题;全片跑 boundary-rewrite(定性合规化)+ check-content-boundary.py
   - 完成标准: 双总结不统一结论(观众自己判断);边界扫描 PASS

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 单一立场的研究解说(企业研究定位内容,默认用叙事弧)
- 事实无争议的选题(硬造辩论 = 降智)
- 无真人链路时仍要求"即兴交锋"(必须预编排,否则两个 AI 念稿)

### 参考视频警告的失败模式

- 情绪化定性越界(「泡沫的特征」「吃干 A 股投资者」)——必须 boundary-rewrite
- 数据选择性引用(双方都不呈现全貌)——我们的 Editorial Master 裁决机制是防线
- 真人即时交锋不可自动化(22 分钟依赖临场发挥)

### 我们的内容边界

- 双总结不得出现目标价/评级/买卖建议(「买未来」类表述需改写为「增长假设验证」)
- 互动钩子不得诱导交易(「你看好还是担心」是观点引导,允许)

### 容易混淆的邻近方法论

- 多空局 ≠ 采访: 采访是问答,多空局是立场交锋
- 预编排 ≠ 即兴: 自动化必须写死脚本,「自由发挥」是降级
