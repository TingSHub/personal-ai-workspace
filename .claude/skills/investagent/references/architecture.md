## 执行路径详解

### 路径A: 主题研究全流程
```
用户输入 → 请求分类
    │
    ├─ Step 1: Serenity 产业链扫描
    │   ├─ 设定范围（市场+主题+时间窗口）
    │   ├─ 故事转系统变化
    │   ├─ 8层价值链映射
    │   ├─ 稀缺层识别
    │   ├─ 构建公司宇宙（≥20家）
    │   ├─ 收集证据（≥25源）
    │   └─ 输出: 优先研究清单
    │
    ├─ Step 2: Buffett 快速筛选
    │   ├─ 对候选池Top5执行8问检查表
    │   ├─ 淘汰不通过标的
    │   └─ 输出: 筛选通过的标的（通常2-3只）
    │
    ├─ Step 3: UZI 深度分析
    │   ├─ 对Top2标的执行22维数据采集
    │   ├─ 65位评审量化裁决
    │   ├─ 6种估值建模
    │   └─ 输出: Bloomberg风格HTML报告
    │
    ├─ Step 4: TradingAgents 多空辩论
    │   ├─ 分析师团队出报告
    │   ├─ 研究员多空辩论
    │   ├─ 交易员决策
    │   ├─ 风控评估
    │   └─ 输出: 交易决策报告
    │
    └─ Step 5: QuantDinger 策略回测
        ├─ 将投研结论转为Python策略
        ├─ 确定性回测
        └─ 输出: 净值曲线+交易明细
```

### 路径B: 个股研究全流程
```
用户输入（股票名称/代码） → 请求分类
    │
    ├─ Step 1: Buffett 快速筛选
    │   └─ 8问检查表（2分钟判断）
    │
    ├─ Step 2: UZI 深度分析
    │   └─ 22维+65人+6种估值
    │
    ├─ Step 3: TradingAgents 多空辩论
    │   └─ 多Agent决策
    │
    └─ Step 4: QuantDinger 回测
        └─ 策略验证
```

## 模块间数据流

```
Serenity → 候选公司列表（ticker list）
    ↓
Buffett → 筛选结果（pass/fail + 理由）
    ↓
UZI → 深度分析产物（.cache/{ticker}/）
    ↓
TradingAgents → 交易决策（buy/hold/sell + 置信度）
    ↓
QuantDinger → 回测结果（净值曲线 + 指标）
```

## 关键设计原则

1. **渐进式加载**: 每个模块只在需要时才读取其SKILL.md和参考文件
2. **数据不编造**: 所有数据必须来自脚本输出或web search
3. **矛盾呈现**: 不同模块结论冲突时，强调分歧本身是信息
4. **研究导向**: 不做买卖建议，不预测价格
5. **可中断恢复**: 每个Step独立可执行，支持从任意步骤继续
