# 四种财经幽默模式指南

## 路由规则

先看视频要解决的观众任务，不看公司名称：

| 观众任务 | 模式 | 首要问题 | 默认收束 |
|---|---|---|---|
| 今天市场怎么了，我该看什么 | 行情陪伴型 | 变化是价格、情绪、资金还是基本面 | 观察变量 |
| 这份财报到底好不好 | 账本预期差型 | 哪些已经兑现，哪些只是结构变化或故事 | 待验证信号 |
| 这家公司到底怎么赚钱 | 生意拆解型 | 价值链哪一环能转成收入、利润和现金 | 最薄弱一环 |
| 这个估值/机制到底怎么理解 | 机制翻译型 | 一个抽象规则如何影响真实结果 | 证明或证伪条件 |

不要在一条短视频里同时回答四个首要问题。若题目可以进入多个模式，先选一个作为主线，其他内容降为一句背景或下一期候选。

## 模式 A：行情陪伴型

### 适合的事实

价格变化、板块相对强弱、成交/资金、新闻触发、市场预期变化。没有行情证据时，必须降级为“市场预期风险解读”，不能伪装成行情复盘。

### 段落骨架

1. 说出观众的感受：又跌、追不上、看不懂轮动，但不要把情绪写成普遍事实；
2. 指出今天真正变化的一件事；
3. 区分市场正在交易的预期和公司已经交付的事实；
4. 给出一到三个跟踪变量；
5. 用“暂时看什么”结束，不用“赶紧做什么”结束。

### 适合的幽默

自嘲误判、市场像排队但队伍不断换窗口、信息很多但有效信息很少。行情明显下跌时，笑点落在噪声和机制，不落在亏损者身上。

## 模式 B：账本预期差型

### 适合的事实

收入、利润、现金流、毛利率、业务结构、市场一致预期和管理层口径之间的差异。

### 段落骨架

1. 用两个方向相反的数字开题；
2. 记“已发生的改善”；
3. 记“旧业务或反证”；
4. 记“未来项目和兑现缺口”；
5. 给出当前能承认的判断，以及还不能承认的判断。

### 适合的幽默

三本账、成绩单、报销单、结账时间不同。比喻要让证据分层更清楚，不能把财务事实变成家庭故事。

## 模式 C：生意拆解型

### 适合的事实

产品、客户、资产、渠道、产业链位置、收入来源、成本、回款和资本开支。

### 段落骨架

1. 先拆掉一个过大的标签；
2. 选择一条价值链；
3. 解释谁付钱、为什么付、公司留下什么；
4. 找到从“有资源/有规模”到“有利润/有现金”的断点；
5. 用一个可观察的经营信号收束。

### 适合的幽默

把“签约、规划、管理规模、订单、收入”放在同一条流水线上核对，但明确每一站不是同一种证据。不要用“故事很大”替代商业闭环。

## 模式 D：机制翻译型

### 适合的事实

估值方法、现金流、资本开支、周期、回报机制、护城河、折现和敏感性。

### 段落骨架

1. 从一个普通投资者会问的问题开头；
2. 只定义一个机制；
3. 用熟悉动作做类比；
4. 明确类比失效的地方；
5. 回到真实公司事实，提出验证条件。

### 适合的幽默

把估值比成“先付学费还是先看到成绩”“排队拿号还是已经拿到货”，但不能把类比当成预测，更不能用幽默掩盖参数和不确定性。

## 双人承接规则

- A 先说观众直觉或情绪，B 不立即背数据，先把问题说得更具体；
- B 给证据后，A 用一句口语复述，确认观众听懂；
- 幽默通常由一方抛出，另一方把它接回事实；
- 每回合只推进一个判断，不让两位主持人各自拥有一套独立论证；
- 最后一回合不追求包袱，追求观察变量或验证窗口。
