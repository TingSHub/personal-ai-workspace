# 外部机制到本地财经规则的转译表

这份表记录“吸收了什么”，也记录“明确没有吸收什么”。本 Skill 吸收的是可迁移的写作机制，不是外部作者的身份、原句、专属梗、表演文本或人格设定。

## 1. 文明反差与锋利表达

| 可迁移机制 | 财经化转译 | 不继承 |
|---|---|---|
| 观点要有态度，不把所有话说成中性摘要 | 先说观众真正困惑的矛盾，再用证据支撑一个有限判断 | 具名作者的口头禅、句式指纹和直接模仿 |
| 反讽来自事实冲突 | 用收入/利润、规模/利润、协议/收入等证据层级差异制造反差 | 人身攻击、低俗、阴阳具体个人 |
| 自嘲降低攻击感 | 承认自己第一眼也容易被概念带走，再展示如何校正 | 为了亲近而虚构个人经历 |
| 短句和留白增强力度 | 口播中把一个判断拆成两到三拍，少做解释性复述 | 全文短句轰炸和连续金句 |

## 2. 账本式冷幽默

| 可迁移机制 | 财经化转译 | 不继承 |
|---|---|---|
| 用一个严肃框架处理一个具体事实 | 用“几本账/几张成绩单/一条链”区分已发生、结构变化、未来期权 | 原语料中的特定物件、人物关系和标志性梗 |
| 精确核算让荒诞自行显形 | 数字必须有来源并参与判断，不能只做装饰 | 伪造数字、对话、价格或机会成本 |
| 逐级抬高后落到一个小细节 | 从宏大叙事回到收入、订单、回款、利润或现金 | 为了反高潮强行追加无关细节 |

## 3. 通用喜剧技法

| 可迁移机制 | 财经化转译 | 不继承 |
|---|---|---|
| 预期—转折—回收 | 先接住观众直觉，再用反证改写直觉，最后回到观察变量 | 具名演员的个人风格标签和模仿指令 |
| 生活类比 | 用排队、记账、交学费、买单等熟悉动作解释专业机制 | 把类比当成公司事实 |
| 情绪浓度自适应 | 行情低迷时先共情，重大亏损时关闭幽默，普通行情才增加轻松感 | “永远搞笑”的人格强制 |
| 善意吐槽和向上攻击 | 吐槽信息噪声、概念包装和证据跳跃 | 吐槽普通投资者、弱势群体或真实损失 |

## 4. 本地财经内容工程的补强

- 外部写作技能解决“怎么说”，但本 Skill 还必须保留财经内容工程的“事实零漂移、证据等级、口播理解和合规边界”。
- 幽默点必须能标记 `fact_anchor` 和 `served_judgement`；无法回指的笑点默认删除。
- 四种模式不是四种人格，而是四种观众任务：陪伴、核对、理解生意、学习机制。
- 生产中优先使用本地四套土豆语料 DNA 的结构和节奏观察，外部技能只作为表达技法补充；不把参考账号变成我们的身份。

## 吸收原则

最终本地化目标不是“像谁”，而是形成一个可识别的财经表达判断：站在中小投资者一边，把难懂的东西讲白，把漂亮故事拆成证据层级，偶尔让人笑一下，但笑完知道下一步要看什么。
