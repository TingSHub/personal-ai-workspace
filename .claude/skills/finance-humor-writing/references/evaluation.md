# 评测与迭代方法

## 同题对照

用同一研究包、同一主线、同一事实和大致相同长度，至少比较：

1. 原始财报式基线；
2. 账本预期差型；
3. 轻锋反差增强版；
4. 行情陪伴或机制翻译的同题异主线版（如果题目适用）。

一次只改变表达层，不同时替换事实、标题、镜头或配音。否则无法判断风格到底带来了什么。

## 人工评分量表

每项 1–5 分，必须写一句证据，不给只有总分的印象分：

| 维度 | 5 分标准 |
|---|---|
| 观众站位 | 开头准确接住观众的情绪或困惑，没有训诫感 |
| 可看性 | 前三句有清晰冲突，信息推进有节奏 |
| 通俗度 | 非专业观众能复述主判断，类比没有制造新疑问 |
| 幽默有效性 | 笑点帮助理解事实，不靠密集梗撑场 |
| 财经稳定性 | 数字、时间、口径、证据等级和结论零漂移 |
| 主线纯度 | 全文只服务一个观众任务，不在财报、行情、估值之间跳线 |
| 人味 | 像一个具体的人在和观众核对，而不是模板拼接 |
| 合规边界 | 没有自创建议、绝对化承诺或未经支持的定性 |

## 硬性不通过条件

出现以下任一情况，不因幽默分高而通过：

- 新增事实或改动数字口径；
- 把规模、协议、规划、签约写成收入或利润；
- 删除反证以换取更鲜明的标题或结论；
- 以普通投资者亏损、弱势群体或真实悲伤为笑点；
- 直接模仿具名人物或复制参考语料中的专属表达；
- 观众听完只记住了段子，不知道下一步看什么。

## 成片复盘指标

进入真实视频后，不能只看“有没有人说好笑”，还要记录：

- 前 3 秒和前 10 秒留存；
- 关键判断出现前的流失点；
- 评论中观众复述的是事实、判断还是单纯笑点；
- 是否出现“讲得有趣但没听懂”“太像段子”“像在推荐”的反馈；
- 同一模式连续使用后，是否出现审美疲劳。

复盘结论只能回写为具体规则，例如“财报类每段只保留一个比喻”“行情低迷时把幽默浓度降到轻度”，不要写成“以后更自然”“多一点人味”这种无法执行的口号。
