# 财经幽默写作

这不是把财经内容变成段子，而是把“观众本来就有的困惑”说得更像人，再用一个准确、具体、有画面的表达帮助他记住判断。

外部参考技能只提供了可迁移的机制：文明反差、账本式冷幽默、事实落地、共情、自嘲、生活类比和节奏控制。本 Skill 不复制外部原句、人物口吻、专属梗或表演语料，也不把任何外部人格直接注入账号。

## 适用边界

调用前必须已经明确：

- 内容主线：行情、财报预期差、公司/产业链或估值/机制；
- 观众此刻的状态：焦虑、困惑、兴奋、失望、观望或想学习；
- 核心事实与来源；
- 这条视频希望观众最后带走的一个判断；
- 幽默浓度：关闭、轻度或标准。

如果主线、事实或结论没有冻结，先退回研究或内容导演，不用幽默填补研究缺口。幽默只能改变表达，不能改变事实权重、证据等级和判断强度。

## 四种表达模式

由上游主线 Agent 选择模式；不要因为同一家公司有多个业务，就在一条短视频里混用四种模式。

### 1. 行情陪伴型

适用：每日行情、板块轮动、市场低迷或市场情绪明显变化。

观众契约：先承认“我为什么烦/看不懂”，再说明今天到底变了什么，最后给出一到三个可观察变量。

结构：

1. 接住情绪，但不放大恐慌；
2. 把市场变化说成一个具体现象；
3. 区分价格、情绪、资金和基本面，不能互相代替；
4. 给出下一步观察什么，而不是给买卖动作。

幽默方式：轻微自嘲、生活类比、对市场“先兴奋后冷静”的反差。行情下跌涉及真实损失时，不拿亏损者开玩笑；笑点应落在市场机制、信息噪声或自己的误判上。

### 2. 账本预期差型

适用：财报解读、利润与现金流背离、收入承压但利润改善、市场预期与实际结果不一致。

观众契约：回答“这份成绩单到底该看哪一科”。

结构：

1. 先亮出最反直觉的数字冲突；
2. 分开已经发生的改善、结构变化和未来故事；
3. 说明市场可能误读的地方；
4. 用一个仍待验证的变量收束。

默认使用“几本账”或“几张成绩单”的框架，但每次只保留一个主比喻。数字参与推理，不能只是装饰。

### 3. 生意拆解型

适用：公司逻辑、产业链、商业模式、产品与客户关系、传统业务转型。

观众契约：回答“这家公司到底靠哪一环赚钱，故事如何变成现金”。

结构：

1. 先把公司从标签中拆出来；
2. 只选一条价值链：资源/资产 → 产品或服务 → 客户付费 → 利润和现金；
3. 用一个日常动作或交易场景翻译专业机制；
4. 找出链条中最薄弱、尚未兑现的一环。

幽默方式：把“规模、签约、框架、规划、订单、收入、利润”故意放到同一张生活账单里对照，但必须明确它们不是同一种证据。

### 4. 机制翻译型

适用：估值教学、现金流、资本开支、周期、护城河、回报机制等抽象概念。

观众契约：观众离开视频时，能用一句自己的话复述这个机制。

结构：

1. 从一个真实的投资困惑开始；
2. 只讲一个机制，不堆概念；
3. 用生活类比解释，再立即说明类比哪里会失效；
4. 回到公司事实，给出“什么证据能证明/证伪”。

不能为了易懂而把估值方法写成公式崇拜，也不能把教学示例伪装成公司事实。没有足够估值数据时，明确退回机制教学，不擅自补倍数、目标价或收益预期。

详细的模式选择、输入字段和段落骨架见 [references/mode-guides.md](references/mode-guides.md)。

## 通用幽默引擎

默认按照“共情 → 事实 → 反差 → 回到判断”推进。

### 先共情

把观众的真实困惑说出来，例如“收入在跌，利润却在涨，看到这里很容易不知道该信谁”。共情不是替观众下结论，更不是制造焦虑。

### 再落事实

幽默前后都要能回指事实。优先使用：具体数字、动作、价格、时间、口径差异、已实现与未实现的落差。数字没有来源就不写；模糊记忆不补齐。

### 只选一种反差机制

- 账本：把业务变化放进几笔账里核对；
- 成绩单：把不同业务的“得分”与“还没交卷”并置；
- 生活类比：用买东西、排队、交学费、家庭记账等场景解释机制；
- 轻反讽：让事实自己暴露矛盾，不替观众把笑点喊出来；
- 自我修正：承认自己第一眼也容易误读，再展示如何校正。

一段只用一种主机制，必要时加一个轻微的回收，不做连续比喻和梗的串烧。

### 最后落判断

笑点结束后必须回到主线：已经发生什么、还没发生什么、下一步看什么。财经视频的记忆点服务于判断，不服务于表演。

完整的技法组合、适用场景和财经改写示例见 [references/humor-patterns.md](references/humor-patterns.md)。

## 浓度控制

| 浓度 | 适用场景 | 允许的表达 |
|---|---|---|
| 关闭 | 重大亏损、风险警示、复杂数字、用户明确要求严肃 | 白描、清晰因果、无额外修辞 |
| 轻度 | 默认财经口播、行情陪伴、财报解读 | 每个主要段落最多一个类比或轻反差 |
| 标准 | 账号开场、公司故事、机制教学 | 一处开场钩子 + 一处中段反差 + 具体收束 |

标准浓度也不能让每句话都像包袱。若观众需要回看才能听懂，先降幽默浓度，不要提高解释密度。

## 财经口播写法

- 第一处冲突尽量在前三句出现；
- 单句以适合朗读为准，过长句拆开，但保留因果关系；
- 每次只压低一到两个数字记忆峰值，其他数字用结构或趋势表达；
- “规模、协议、规划、订单、收入、利润、现金”必须保留证据层级差异；
- 术语第一次出现时用一句白话解释，之后可以使用简称；
- 不依赖连续排比、万能金句、口号式升华或“不是 A 而是 B”的机械重复；
- 双人稿中，幽默应由一方抛出，另一方接住并把话题带回证据，不能两个人轮流念单口段子。

账号的人味、观众站位和“什么时候应该陪伴而不是逗笑”的细则见 [references/voice-contract.md](references/voice-contract.md)。

## 账号级红线

禁止：

- 编造数字、对话、订单、客户反应、市场情绪或内幕动机；
- 把框架合作、规划装机、管理规模、签约数量写成收入、利润或现金流；
- 自创目标价、评级、买卖建议、仓位和收益保证；
- 用“泡沫、骗局、收割”等断言式情绪词替代可验证的事实冲突；
- 拿普通投资者的亏损、弱势群体、真实悲伤或重大损失开玩笑；
- 直接模仿具名作者、演员、博主或参考账号的标志性口吻；
- 为了好笑而删掉反证、风险、时间范围或数据口径。

外部参考机制如何被转译为本地规则，以及哪些内容明确不继承，见 [references/distillation-map.md](references/distillation-map.md)。

## 输出契约

正常生产时输出：

1. `expression_mode`：四种模式之一；
2. `viewer_contract`：观众状态、核心问题、观看承诺；
3. `polished_script`：可直接进入后续口播编排的稿件；
4. `humor_map`：每个幽默点的类型、事实锚点和服务的判断；
5. `fact_preservation_check`：数字、时间、口径、证据等级和结论是否保持不变；
6. `downgrade_note`：材料不足或观众情绪不适合幽默时，说明降级原因。

用户只要成稿时，不展示内部标签，但仍在内部完成上述检查。

## 交付前验收

- 前三句能说清观众为什么要继续听；
- 去掉所有幽默后，事实链和结论仍然成立；
- 每个笑点都能回指一个事实、一个机制或观众的真实感受；
- 同一条稿件没有同时争夺多个主线；
- 没有把“未来可能”说成“已经兑现”；
- 读出来不需要观众停下来解谜；
- 最后一句落到判断、观察变量或验证窗口，不落到口号。
