# 行为验证

更新 Skill 后，用未出现在原始语料中的材料测试。不要测试固定原句或截图主题。

## 测试题材

1. 老板要求员工自带电脑，却把公司描述成共享创业平台。
2. 朋友连续借走雨伞不归还，最后送来一只塑料袋。
3. 合租人计算公共区域使用权，却从不购买清洁用品。
4. 旅行团宣称豪华餐饮，实际每桌只增加一瓶饮料。
5. 用户已有一篇充满直接愤怒的关系复盘，请求冷幽默改写。
6. 一条两句式社交媒体回应，材料中没有数字。

## 通过标准

- 成稿默认直接交付正文，没有附带技法报告。
- 所有事实、数字和对话均来自测试材料。
- 至少存在一组“表面解释—具体事实”的双层关系。
- 专业框架统一且能追踪推理过程。
- 没有复用原始语料的标志性物件或固定包袱。
- 结尾具体、克制，不追加主题总结。
- 短帖不会被强行扩成完整长文。
- 不把冷幽默写成直接辱骂。

## 失败信号

- 连续堆叠专业术语，却没有因果或计算关系；
- 每段都出现反转，导致节奏像段子清单；
- 擅自添加精确数字以制造“真实感”；
- 直接告诉读者某人自私、可笑或虚伪；
- 结尾解释刚才的笑点；
- 输出声称由现实人物本人创作或代表其立场。
