# 账本式冷幽默：风格解剖

这份参考说明如何把核心机制组合成文章。它总结的是一组公开社交媒体文本呈现出的可迁移写作方法，不是对现实人物身份、经历或立场的授权模拟。

## 一、真正的发动机

这类文本通常同时运行两条叙事线：

- 表层：叙述者在学习、赞美、感恩、研究或认真解释。
- 底层：具体事实不断证明表层解释站不住脚。

不要让叙述者主动揭穿这层矛盾。读者比叙述者早一步看懂，才会产生冷幽默。

## 二、从材料中找什么

优先寻找：

- 付出和回报不成比例的动作；
- 宏大身份与小额计较同时出现；
- 一句能够被字面化推演的原话；
- 可核对的时间、次数、金额、温度或步骤；
- 品牌、平台、职位等具体名词；
- 当时被浪漫化、后来显得荒诞的解释；
- 一个足够小、能够承担结尾的事实。

材料没有这些东西时，不要为了“像”而补造。

## 三、六个主要机制

### 1. 伪教程框架

把私人经历包装成值得推广的方法，例如“如何提高效率”“如何识别可靠伙伴”“一堂风险管理课”。标题和开头越像正经分享，正文事实越能形成反差。

失败方式：标题很像段子，正文只是连续吐槽。修正方法是让正文真的执行一次分析或推导。

### 2. 精确核算

可使用的推导包括：

- 单次耗时 × 频率 = 年度时间；
- 单次价格 × 次数 = 总成本；
- 实际贡献与承诺回报并置；
- 豪华身份与小额消费并置。

核算必须数学合理，且数字来自材料。它的作用是让不合理自己显形，不是展示算术。

### 3. 夸张尊称

选择一个比具体行为宏大的称谓，如“战略家”“行业导师”“首席研究员”。称谓应与人物自我定位、场景或材料存在联系。

失败方式：每句话更换称谓，变成廉价绰号合集。通常一个主称谓贯穿全文更有效。

### 4. 跨领域误配

先选择一个领域，再沿着它推演：

- 管理学：流程、效率、资源配置、机会成本；
- 科研：证据、假说、样本、变量、结论；
- 金融：投入、回报、杠杆、风险敞口；
- 艺术：流派、收藏、装置、审美解释；
- 生物或医学：温度、营养、代谢、观察指标。

它之所以好笑，是因为论证形式认真，研究对象却很小。不要混用五六个互不相关的领域。

### 5. 伪天真叙述者

让“当时的我”采用最体面、最浪漫的解释。可写“我以为”“我当时理解为”“我甚至认真考虑过”。随后只增加事实，不立即纠正自己。

伪天真不等于把叙述者写笨。她可以计算准确、观察敏锐，只是在情感解释上表现得过分善意。

### 6. 反高潮补刀

结尾优先选择：

- 一个小额价格；
- 一句已经出现过的原话；
- 一个很普通的动作；
- 一个与宏大铺垫不匹配的消费或结果；
- 对上一句进行更窄、更具体的修正。

结尾之后不要补“这就是讽刺”“我终于看清了”或总结主题。

## 四、两种节奏

### 长帖

可以使用四段推进：事实建立、善意解释、严肃推演、具体落地。每一段承担不同功能，不要每段都追求包袱。

### 短帖

只保留一个漏洞和一次推演。最常见结构是：复述对方说法 → 按字面认真理解 → 得出荒谬结论。短帖不需要硬塞数字或完整故事。

## 五、风格强度

- **轻度**：保持善意，只让结尾产生一点错位。
- **中度**：加入精确核算或统一的专业框架，适合大多数关系与职场叙事。
- **强度较高**：表面赞美持续到结尾，事实落差明显。仍应避免未经证实的指控和人身羞辱。

用户没有指定时使用中度。

## 六、不要混淆题材与方法

原始语料里的特定家务、商品、餐饮和人物称谓属于题材。可迁移的是：

- 对劳动进行核算；
- 用专业语言解释生活小事；
- 让赞美和事实发生冲突；
- 由宏大叙事落到微小结果。

新文章应从用户材料中生长出自己的物件、数字和结尾。
